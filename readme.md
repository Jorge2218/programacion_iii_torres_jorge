## Descripción

Este repositorio contiene los trabajos, prácticas, ejercicios y proyectos desarrollados durante la materia **Programación III**.

A lo largo de la asignatura se estudiarán diferentes tecnologías y herramientas orientadas al desarrollo web, desde los fundamentos del desarrollo frontend hasta la creación de aplicaciones modernas utilizando frameworks como **ReactJS** y **NestJS**.

---

## Tecnologías y conceptos

### HTML

**HTML (HyperText Markup Language)** es el lenguaje utilizado para estructurar el contenido de una página web.

Permite definir elementos como:

- Títulos
- Párrafos
- Imágenes
- Enlaces
- Formularios
- Tablas
- Listas

---

### CSS

**CSS (Cascading Style Sheets)** se utiliza para diseñar y dar estilo a las páginas web.

Permite controlar aspectos como:

- Colores
- Tipografías
- Tamaños
- Márgenes y espacios
- Posicionamiento
- Diseño responsivo
- Animaciones

---

### JavaScript

**JavaScript** es un lenguaje de programación utilizado principalmente para agregar interactividad y comportamiento dinámico a las páginas web.

Entre sus principales características se encuentran:

- Variables y constantes
- Funciones
- Condicionales
- Bucles
- Objetos
- Arrays
- Eventos
- Manipulación del DOM
- Programación asíncrona

---

### TypeScript

**TypeScript** es un lenguaje basado en JavaScript que incorpora tipado estático y otras características que facilitan el desarrollo de aplicaciones grandes y mantenibles.

Permite trabajar con:

- Tipos de datos
- Interfaces
- Clases
- Genéricos
- Enumeraciones
- Tipado estático
- Programación orientada a objetos

---

### NestJS

**NestJS** es un framework para desarrollar aplicaciones del lado del servidor utilizando **Node.js** y **TypeScript**.

Se utiliza principalmente para construir APIs y aplicaciones backend escalables.

Algunos conceptos importantes son:

- Módulos
- Controladores
- Servicios
- Inyección de dependencias
- DTOs
- Middleware
- Guards
- APIs REST
- Manejo de excepciones

---

### ReactJS

**ReactJS** es una biblioteca de JavaScript utilizada para construir interfaces de usuario modernas y dinámicas.

Su desarrollo se basa principalmente en componentes reutilizables.

Entre sus conceptos principales se encuentran:

- Componentes
- JSX
- Props
- State
- Hooks
- Eventos
- Formularios
- Renderizado dinámico
- Consumo de APIs
